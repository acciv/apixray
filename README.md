# 🩻 apixray

так. это самый сложный проект который я делал. честно. даже сложнее чем лаба по информатике.

я решил сделать штуку которая смотрит на API ключ и говорит "ага, это гитхаб, тут 2 куска, энтропия 4.5, риск 60, вроде фейк". как в фильмах где хакеры, только без взлома. потому что мама сказала не взламывать, да и мне ещё математичку доделать надо.

## важное (серьёзно)

оно НЕ подбирает ключи. НЕ взламывает. НЕ обходит авторизацию. я не такой. оно просто разбирает КАК устроен ключ:
- какой провайдер (гитхаб, openai, aws, слак, телеграм, jwt и ещё пару)
- на какие куски он делится
- насколько он рандомный (энтропия, я сначала подумал что это про энтропию из физики, но вроде похоже)
- декодирует JWT-пейлоады без проверки подписи (подпись проверять надо на сервере, я прочитал в интернете)

и генерирует ФЕЙКОВЫЕ ключи с надписью TEST. они не работают, я проверял. ну почти проверял.

## что умеет

- определяет 9 провайдеров по префиксам (`ghp_`, `sk-proj-`, `AKIA`, `xox`...)
- режет ключ на сегменты и подписывает каждый (`prefix`, `payload`, `signature`)
- считает энтропию Шеннона (звучит страшно, это просто цифра от 0 до 8)
- разбирает JWT: `alg`, header, payload. если `alg: none` — прям кричит "опасность!"
- ищет ключи в тексте и маскирует их (`ghp_...cdef`)
- делает фейковые ключи для тестов, чтобы не светить настоящие

## сборка

```bash
cargo build --release --workspace
cargo test --workspace
```

или в докере (он у меня установился с первого раза, я в шоке):

```bash
docker build -t apixray .
docker run --rm apixray generate github
```

## команды

```bash
apixray inspect ghp_хххх...        # разобрать ключ
apixray scan ./проект              # найти ключи в файле
apixray scan-text 'token = sk-...' # найти в строке
apixray jwt eyJ...                 # разобрать JWT
apixray generate aws               # сделать фейковый ключ
apixray version
```

всё выводится в JSON, потому что так удобно, а я уже начал привыкать.
